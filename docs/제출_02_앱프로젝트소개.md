**앱명 / 프로젝트명:** SLEEP CLIMATE (슬립 클라이밋) — 차박·정차 중 휴식용 자동 실내 온도 관리 앱

---

## 1. 앱 한 줄 소개

잠들기 전에 목표 온도와 휴식 시간을 한 번만 정하면, 자는 동안 차가 알아서 냉방·난방을 켜고 끄고 배터리가 부족하거나 위험할 때만 깨워 주는 차박·차내 휴식 전용 공조 관리 앱입니다.

---

## 2. 기획 배경

차박·캠핑, 장거리 운전 중 휴게소 쪽잠, 출장 중 차내 휴식처럼 **차 안에서 잠을 자는 순간**이 늘고 있습니다. 그런데 잠든 뒤 바깥 기온에 따라 실내가 덥거나 추워지면, 결국 깨어나 공조를 직접 켜고 꺼야 합니다. 그때마다 잠이 끊기고, 반대로 공조를 켜 둔 채 깊이 잠들면 배터리 방전, 과냉·과열, 공회전 상태의 수면 같은 걱정이 생깁니다.

기존 원격·예약 공조는 '정해진 시각에 켜고 끄는 버튼'에 가깝습니다. 취침 시간, 허용 온도 범위, 기상 시각, 배터리 보호, 이상 상황 알림을 **하나의 흐름으로 관리**해 주지는 않습니다.

잠든 사람은 공조를 조작할 수 없습니다. 그래서 사용자가 잠들기 전 한 번 정한 조건대로 **차가 대신 판단하고, 꼭 필요할 때만 깨우는** 휴식 관리가 필요하다고 보았습니다.

---

## 3. 앱 주요 기능 및 차량 특화 요소

**① 휴식 세션 — 한 번 설정**
목표 온도, 허용 범위(±1~3°C), 휴식 시간, 배터리·연료 보호 기준을 한 화면에서 정합니다. '여름 차박 / 겨울 차박 / 짧은 휴식' 모드 타일을 누르면 값이 채워져 있어 두 번의 터치로 시작할 수 있습니다.

**② 자동 공조 제어**
실내 온도가 허용 범위를 벗어나면 냉방 또는 난방을 켜고, 목표 온도에 도달하면 끕니다. 명령을 보낸 것만으로 성공 처리하지 않고, 차량 상태에서 실제 반영을 확인해야 '반영 확인'으로 기록합니다. 실패가 3회 쌓이면 자동 제어를 멈추고 직접 조작을 안내합니다.

**③ 안전·에너지 보호**
P(주차) 상태에서만 세션을 시작하고 제어합니다. 배터리·연료가 보호 기준 이하로 떨어지면 공조를 끄고 자동 제어를 중단한 뒤 음성으로 깨웁니다. 차량 연결 끊김이나 데이터 지연도 바로 알립니다.

**④ 잠들기 → 수면 → 기상 단계**
30초간 조작이 없으면 눈부심 없는 수면 화면으로 바뀝니다. 기상 10분 전부터는 허용 범위를 좁혀 실내를 목표 온도에 미리 맞추고, 화면이 일출처럼 서서히 밝아집니다. 기상 화면에서 '10분 더 쉬기'를 고를 수 있고, 응답이 없으면 5분 뒤 자동 종료해 공조를 무기한 켜 두지 않습니다.

**⑤ 음성 명령·음성 안내**
누운 채로 "여름 차박 시작해줘", "온도 좀 올려줘", "지금 몇 도야", "10분만 더 잘게"라고 말하면 됩니다. 음성 안내는 휴식 시작·기상·위험 알림 때만 나오고, 자동 제어가 정상일 때는 조용히 둡니다.

**⑥ 휴식 리포트**
밤사이 실내 온도 그래프, 허용 범위 유지율, 자동 제어 횟수와 반영 확인 횟수, 알림 내역을 보여 줍니다.

**차량 특화 요소**
- 차량 실내 온도·공조 상태·배터리·기어 데이터를 직접 읽고 공조를 제어합니다. 스마트폰 앱으로는 실내 온도를 알 수도, 공조를 켤 수도 없어 차량에서만 가능한 경험입니다.
- 주행이 아닌 '정차·휴식' 맥락에 맞춰 설계했습니다(주차 상태 확인, 주행 감지 시 중단).
- 차량 중앙 디스플레이에 맞춘 가로 와이드 화면, 2앱 분할 화면 대응, 야간용 수면 화면, 위에서 내려다본 차량 실내 렌더(공조 바람 흐름 표시)로 상태를 한눈에 보여 줍니다.

## 4. 주요 사용 시나리오

**시나리오 1 — 여름 차박 (주말 캠핑 이용자)**
① 밤 11시, 외기 28°C인 캠핑장에 주차하고 뒷좌석을 펼칩니다.
② 누운 채로 "여름 차박 시작해줘"라고 말하면 목표 22°C, 8시간 세션이 시작되고 "8시간 뒤에 깨워드릴게요"라고 안내합니다.
③ 30초 뒤 화면이 어두운 수면 화면으로 바뀝니다.
④ 새벽에 실내가 23.5°C를 넘으면 냉방이 켜지고, 22°C가 되면 꺼지는 과정이 밤새 반복됩니다. 사용자는 깨지 않습니다.
⑤ 6시 50분부터 실내를 목표 온도에 맞추며 화면이 밝아지고, 7시에 기상 화면이 나옵니다.
⑥ 리포트에서 밤사이 온도 변화와 허용 범위 유지율을 확인합니다.

**시나리오 2 — 겨울 장거리 운전 중 휴게소 쪽잠**
① 영하의 휴게소에 주차한 뒤 '짧은 휴식' 또는 '겨울 차박'을 선택하고, 배터리 보호 기준을 30%로 둡니다.
② 실내가 내려가면 난방이 자동으로 켜집니다.
③ 배터리가 기준 이하로 떨어지면 공조를 끄고 "에너지 잔량이 기준 이하라 자동 제어를 중단합니다"라고 음성으로 깨웁니다.

**시나리오 3 — 반려동물과 함께 휴식**
반려동물 동반을 켜면 30분마다 실내 온도와 환기 상태를 확인하라고 알립니다. 앱의 알림만으로 반려동물의 안전을 확인할 수 없다는 점을 화면에 함께 안내합니다.

## 5. 개발 계획

**현재 구현 범위 (Android·Kotlin, API 28 이상, Jetpack Compose)**
홈, 세션 설정, 세션 진행·수면 화면, 기상 화면, 알림 내역, 휴식 리포트 화면과 자동 공조 제어 로직, Pleos Connect SDK 연동, 음성 명령·안내를 구현했습니다. 앱이 백그라운드로 가도 감시가 이어지도록 포그라운드 서비스를 씁니다. 핵심 로직(자동 제어 규칙, 기상 단계, 알림, 음성 명령 해석)은 단위 테스트 28개로 검증하고 있습니다.

**Pleos Connect SDK / API 사용 계획**

| SDK | 사용 API | 용도 |
|---|---|---|
| Vehicle SDK 2.3.2 – HVAC | `getHvacTemperatureCurrent`, `getHvacTemperature`, `getHvacPowerState`, `getHvacAcState` | 실내 온도·설정 온도·공조 상태 조회 |
| Vehicle SDK 2.3.2 – HVAC | `setHvacPower`, `setHvacAc`, `setHvacAuto`, `setHvacTemperature` | 냉방·난방 켜기·끄기, 목표 온도 설정 |
| Vehicle SDK 2.3.2 – HVAC | `checkHvacTemperatureCurrentCapabilities`, `checkHvacPowerCapabilities`, `checkHvacTemperatureCapabilities` | 차량별 지원 여부 확인 후 기능 활성화 |
| Vehicle SDK 2.3.2 – EvBattery / Fuel | `getEvBatteryStateOfCharge`, `getFuelPercent` | 에너지 보호 |
| Vehicle SDK 2.3.2 – Gear | `getCurrentGearSelectionState` | 주차(P) 상태 확인, 주행 시 중단 |
| SpeechToText SDK 3.3.1 | `initialize`, `request`, `ResultListener` | 음성 명령 인식 (HYBRID 모드) |
| TextToSpeech SDK 3.3.1 | `initialize`, `speak` | 음성 안내 |

- 권한: `CAR_CLIMATE`, `CONTROL_CAR_CLIMATE`, `CAR_ENERGY`, `CAR_DRIVE`. Pleos App Market과 협의한 승인 범위 안에서만 사용합니다.
- 신뢰성 원칙: 지원이 확인된 기능만 화면에 노출합니다. 모든 SDK 호출에 제한 시간을 두고, 응답이 없으면 성공으로 표시하지 않습니다. 재시도는 3회로 제한합니다.
- 공조 제어를 지원하지 않는 차량에서는 '알림 모드'로 동작해, 온도 이탈 시 알림과 직접 조작 안내를 제공합니다.

## 6. 기대효과 및 발전 가능성

**사용자 가치**
- 깨지 않고 이어지는 수면: 온도 변화 때문에 일어나 공조를 조작할 필요가 없습니다.
- 안심: 배터리 보호, 주행 감지, 연결 이상 알림으로 '켜 두고 자도 되나' 하는 걱정을 줄입니다.
- 손 대지 않는 조작: 누운 채 음성으로 시작·조절·연장합니다.

**타깃 고객**
- 차박·캠핑 이용자: 주말·성수기에 반복적으로 차에서 잠을 자는 사용자
- 장거리 운전자·출장자: 휴게소나 주차장에서 30분~2시간 쉬는 사용자
- 전기차 오너: 시동 없이 공조를 오래 쓸 수 있어 핵심 타깃(무시동 공조와 배터리 보호의 결합)
- 반려동물 동반 이용자: 차내 환경 확인 알림이 필요한 사용자

**예상 MAU (가정 기반 추정)**
MAU ≈ Pleos Connect 앱마켓 이용 차량 수 × 차내 숙박·휴식 경험 비율 × 설치율 × 월 1회 이상 사용 비율
예) 이용 차량 10만 대 × 15%(가정) × 20%(가정) × 50%(가정) ≈ 월 1,500명
※ 위 비율은 검증 전 가정이며, 사용자 테스트와 출시 후 실제 지표로 보정합니다.

**Retention 목표 (가정)**
차박은 주말·계절성이 강해 일간보다 월간 재사용이 의미 있는 지표입니다.
- 첫 사용 후 30일 내 재사용률 40% 목표
- 세션 완료율(중도 종료 없이 기상까지) 80% 목표
- 휴식 리포트와 개인 프리셋으로 다음 사용을 유도

**향후 서비스 확대**
1. 위치 연동(FusedLocation SDK): 현재 위치의 야간 최저기온 예보를 반영해 미리 냉난방하고, 일출 시각에 맞춰 기상합니다.
2. 수면 환경 패키지: 좌석 열선·통풍, 창문 미세 환기 등 다른 차량 기능과 연계합니다(SDK 지원 범위 내).
3. 개인화: 지난 리포트를 바탕으로 사용자별 최적 온도와 범위를 추천합니다.
4. 이동 연계(NaviHelper SDK): 장거리 경로에서 휴식 지점을 추천하고, 도착하면 바로 휴식 세션을 제안합니다.
5. 제휴: 캠핑장·차박 플랫폼과 연계하고, 차종·지역을 넓힙니다.
